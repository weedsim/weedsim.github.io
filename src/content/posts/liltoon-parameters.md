lilToon은 아바타용 툰 셰이더 중 가장 널리 쓰이는 축에 든다. MIT 라이선스이고,
인스펙터 UI는 **한국어를 지원한다.** 그래서 처음 만지기는 쉽다.

문제는 그다음이다. 인스펙터에 항목 이름은 한국어로 뜨는데, **그 항목이 정확히
무엇인지 설명하는 공식 문서는 일본어뿐이다.** 그래서 한국어로 lilToon을
검색하면 대부분 그 일본어 문서를 옮긴 2차 자료가 나온다.

옮기는 과정에서 사고가 난다. 예를 들어 한국어 자료에서 이런 항목을 만나게 된다.

> **림 라이트의 벌금** — Rim Shade의 가늘기입니다.

항목명과 설명이 서로 안 맞는다. 원문을 찾아보면 답이 나온다. 실제 프로퍼티는
**「リムライトの細さ」**, 곧 **림 라이트의 가늘기**다. `細さ`(가늘기)를 영어
*fine(ness)* 로 옮긴 뒤, 그 단어의 다른 뜻으로 한 번 더 옮기면서 **벌금**이 된
것이다. 설명문 쪽은 제대로 옮겨졌는데 항목명만 이 경로를 탔다.

그래서 공식 일본어 문서를 항목별로 직접 대조해 정리했다. **기준은 lilToon
2.3.3**이고, 인스펙터에서 자주 쓰는 범위까지 다룬다.

원문 대조가 가능하도록 **일본어 항목명을 같이 실었다.** 인스펙터 언어를
일본어로 바꿔놓고 보거나, 공식 문서에서 해당 항목을 찾을 때 쓰면 된다.

## 목차

## 읽기 전에

- **표시 모드에 따라 보이는 항목이 다르다.** lilToon 인스펙터에는 간이 설정과
  상세 설정이 있다. 아래 항목 중 일부는 상세 설정에서만 보인다.
- **렌더 파이프라인에 따라서도 다르다.** `[Built-in RP]`, `[HDRP]`가 붙은
  항목은 해당 파이프라인에서만 나타난다.
- **문서에 없는 항목도 있다.** 인스펙터에는 있는데 공식 문서에 설명이 없는
  항목이 존재한다. 아래에서 그런 경우는 따로 표시했다.

## 기본 설정 (基本設定)

가장 먼저 정하게 되는, 렌더링의 큰 틀에 해당하는 설정이다.

| 일본어 | 한국어 | 설명 |
|---|---|---|
| 描画モード | 렌더링 모드 | 불투명·컷아웃·반투명·굴절 등 렌더링 종류 |
| Cutoff | Cutoff | 투명도가 이 값 이하가 되면 완전히 투명해진다 |
| Cull Mode (描画面) | 컬링 면 | 지정한 면만 렌더링한다. 양면보다 단면 쪽이 부하가 작다 |
| 裏面の法線を反転 | 뒷면의 노멀 반전 | 뒷면일 때 라이팅 처리를 반전시킨다 |
| 裏面を影にする | 뒷면을 그림자로 | 뒷면을 강제로 어둡게 하는 정도. 옷 안쪽이 부자연스럽게 밝을 때 쓴다 |
| 非表示 | 숨김 | 켜면 머티리얼이 표시되지 않는다 |
| ZWrite | ZWrite | 깊이 정보를 기록할지 여부. 기본은 켜는 쪽을 권장하나, 투과 머티리얼에서는 끄면 개선되는 경우가 있다 |
| Render Queue | 렌더 큐 | 렌더링 순서. 클수록 나중에 그려진다. 투과 머티리얼끼리 겹쳐 한쪽이 사라지면 앞에 둘 쪽의 값을 올려본다 |

`Cull Mode`와 `Render Queue`는 셰이더 고유 기능이 아니라 그래픽스 파이프라인의
래스터라이저·출력 병합 단계에 그대로 대응한다. 반투명이 겹칠 때 순서를 타는
이유도 거기에 있다.

### 렌더링 모드 목록

| 일본어 | 한국어 | 설명 |
|---|---|---|
| 不透明 | 불투명 | 투과를 무시한다 |
| カットアウト | 컷아웃 | 투과를 쓰지만 반투명은 불가능하다 |
| 半透明 | 반투명 | 투과를 쓴다. 반투명끼리 겹치면 한쪽이 안 보일 수 있다. 표정, 머리카락 비침 등에 쓴다 |
| [高負荷] 屈折 | [고부하] 굴절 | 비쳐 보이는 부분이 일그러진다 |
| [高負荷] 屈折ぼかし | [고부하] 굴절 흐림 | 굴절에 더해 젖빛 유리 같은 흐림 효과 |
| [高負荷] ファー | [고부하] 퍼 | 털 표현. 부드럽지만 앞뒤 관계 렌더링이 부자연스러울 수 있다 |
| [高負荷] ファー (カットアウト) | [고부하] 퍼 (컷아웃) | 컷아웃으로 그려 딱딱한 인상. 안티에일리어싱 환경에서는 다소 개선된다 |
| [高負荷] ファー (2パス) | [고부하] 퍼 (2패스) | 투과 퍼와 컷아웃 퍼를 블렌딩해 각각의 단점을 완화한다 |
| [高負荷] 宝石 | [고부하] 보석 | 복잡한 굴절 표현 |

## 라이팅·밝기 설정 (ライティング設定)

문서는 **기본값 사용을 권장한다.** 「프리셋 적용」의 「통상」을 누른 상태가
기준이고, 촬영이나 영상 제작에서 의도적으로 벗어날 때 만지는 영역이다.

| 일본어 | 한국어 | 설명 |
|---|---|---|
| 明るさの下限 | 밝기 하한 | 어두워지는 한도. 완전히 깜깜해지는 것을 막는다. VRChat에서는 0.0~0.2 권장 |
| 明るさの上限 | 밝기 상한 | 밝아지는 한도. 백색 포화를 막는다 |
| ライトのモノクロ化 | 라이트 흑백화 | 라이트의 채도. 색감이 강한 월드를 보정할 수 있으나 주변과 색감 차이가 생긴다 |
| 影色への環境光影響度 | 그림자색에 대한 환경광 영향도 | 주변 광이 그림자 색에 영향을 주는 강도 |
| Unlit化 | Unlit화 | 라이팅을 무효화해 Unlit에 가깝게. 어두운 월드 보정에 쓰이지만, 자신이 밝아지는 만큼 상대적으로 주변 아바타를 어둡게 만드는 것이기도 하다 |
| 頂点ライトの強度 | 정점 라이트 강도 | 정점 단위로 계산되는 포인트·스포트 라이트의 강도. 메시가 여러 개면 0으로 두어 메시별 밝기 차이를 줄일 수 있다 |
| ライト方向のオーバーライド | 라이트 방향 오버라이드 | 라이트 방향에 더하는 벡터. 폴백으로도 쓰이므로 xyz를 모두 0으로 두면 라이트가 없는 조건에서 완전히 어두워질 수 있다 |
| オブジェクトの向きに追従 | 오브젝트 방향에 추종 | 오브젝트가 회전하면 오버라이드 방향도 같이 움직인다 |
| [Built-in RP] ライトの合成 | 라이트 합성 | 추가 실시간 라이트의 합성 방식. 가산은 광학적으로 옳지만 백색 포화가 쉽고, 비교(밝게)는 그 반대다 |
| [HDRP] Before exposure limit | Before exposure limit | Exposure 이전에 적용되는 밝기 제한 |
| [HDRP] Directional Lightの強さ | Directional Light 강도 | 머티리얼에 적용되는 Directional Light 강도 |

이 라이팅 부분은 **OpenLit**이라는 CC0 라이브러리로 따로 공개되어 있다. 직접
셰이더를 만들면서 lilToon과 밝기를 맞추고 싶을 때 쓸 수 있다.

## 색 설정 (色設定)

### 메인 컬러 / 투과 (メインカラー / 透過)

기본이 되는 색이다. 렌더링 모드가 컷아웃이나 반투명이면 텍스처나 컬러 피커의
알파 채널이 투명도로 쓰인다.

| 일본어 | 한국어 | 설명 |
|---|---|---|
| 色 / 透明度 | 색 / 투명도 | 텍스처를 지정한다. 오른쪽 컬러 피커의 색이 곱해진다 |
| 色相 / 彩度 / 明度 / ガンマ | 색상 / 채도 / 명도 / 감마 | 색조 보정. 감마는 대비를 강조한다 |
| グラデーションマップ | 그라데이션 맵 | 색감을 지정한 그라데이션으로 치환한다. RGB 채널별로 적용되므로 그레이스케일화 여부에 따라 결과가 달라진다 |
| 色調補正マスク | 색조 보정 마스크 | 검게 칠한 부분만 색조 보정이 무효화된다. R 채널 사용 |
| 焼き込み | 베이크 | 색조 보정 결과를 텍스처로 내보낸다 |

> **VRChat 세이프티와의 관계.** 여기서 지정한 **텍스처의 색은 세이프티
> 발동 시에도 유지**되지만, **색조 보정으로 편집한 색은 유지되지 않는다.**
> 편집했다면 텍스처로 베이크해 두는 편이 안전하다.

문서는 최종 출력 색에 대해 이렇게 설명한다. 셰이더 안에서 특수한 색 가공은
하지 않고 텍스처 그대로의 색이 나오도록 만들어져 있으며, 다만 **라이트 색의
곱셈만** 수행한다. 라이트가 흰색이면 텍스처 그대로, 어두운 주황색이면 그 색이
곱해진 결과가 나온다.

### 메인 컬러 2nd·3rd (メインカラー2nd・3rd)

메인 컬러 위에 색을 얹는 **레이어**다. 데칼, 미세 질감, 헤어 그라데이션 등에
쓴다. GIF를 변환해 애니메이션시키거나 거리에 따라 페이드시킬 수도 있다.

| 일본어 | 한국어 | 설명 |
|---|---|---|
| テクスチャ | 텍스처 | `Convert Gif`로 GIF를 애니메이션시킬 수 있다 |
| MSDFテクスチャ | MSDF 텍스처 | 사전 변환이 필요하지만 벡터에 가까운 표현이 가능하다 |
| UV Mode | UV 모드 | UV0~3과 MatCap을 쓸 수 있다 |
| デカール化 | 데칼화 | 레이어를 데칼로 사용한다 |
| マスク | 마스크 | 지정한 부분만 합성한다. R 채널 사용 |
| ライティングを適用 | 라이팅 적용 | 라이트 밝기를 적용한다 |
| 合成モード | 합성 모드 | 통상 / 가산 / 스크린 / 곱하기 |
| 開始距離 / 終了距離 / 強度 | 시작 거리 / 종료 거리 / 강도 | 거리 페이드 설정 |
| Tiling / Offset / 角度 | 타일링 / 오프셋 / 각도 | 텍스처 배치 |

데칼화를 켜면 미러 모드, 복제 모드, X·Y 좌표와 크기, 프레임 수와 FPS 같은
항목이 추가로 나온다. 스프라이트 시트를 넘겨 애니메이션시키는 용도다.

### 알파 마스크 (アルファマスク)

투명도를 지정하는 흑백 마스크다. 문서는 **가능하면 쓰지 말 것을 권한다.**
원래 메인 텍스처의 알파 채널에 넣으면 텍스처 한 장으로 끝나는데, 알파 마스크를
쓰면 **샘플링하는 텍스처가 두 장으로 늘어 셰이더 부하가 올라가기 때문**이다.
호환성을 위해 남아 있는 기능이다.

| 일본어 | 한국어 | 설명 |
|---|---|---|
| アルファマスク | 알파 마스크 | None(무효) / 치환 / 곱하기. R 채널 사용 |
| Invert | 반전 | 마스크를 반전한다 |
| Transparency | 투명도 | 투명도 |
| Cutoff | Cutoff | 이 값 이하면 완전히 투명해진다 |
| Scale・Offset | 스케일·오프셋 | `AlphaMask * Scale + Offset`으로 최종 강도가 정해진다. Scale=-1, Offset=1이면 반전이 된다 |
| アルファマスクを焼き込み | 알파 마스크 베이크 | 메인 텍스처에 적용해 굽는다 |

세이프티 발동 시에는 알파 마스크가 무시된다.

### 그림자 설정 (影設定)

lilToon에서 인상을 가장 크게 좌우하는 부분이다. **블러 0이면 애니메이션 채색,
값을 올리면 일러스트풍, 더 올리면 리얼풍**이 된다. 그림자는 **3단계까지**
설정할 수 있어서, 안쪽 그림자 색을 옅게 하면 반사광 같은 표현도 된다.

| 일본어 | 한국어 | 설명 |
|---|---|---|
| マスクタイプ | 마스크 타입 | 「강도」는 검을수록 그림자를 약화시키고, 「평면화」는 검을수록 노멀을 평면화해 입체감을 억제한다 |
| マスクと強度 | 마스크와 강도 | 그림자의 강도. 얼굴만 그림자를 끄는 식으로 쓴다. R 채널 사용 |
| LOD | LOD | 텍스처의 블러 양. MipMap으로 해상도를 낮춰 유사 블러를 만든다 |
| ぼかし量マスク | 블러 양 마스크 | 부분적으로 블러 양을 바꾼다. RGB가 그림자색 1·2·3에 대응 |
| 影色1・2・3 | 그림자색 1·2·3 | 기본적으로 메인 컬러에 곱해진다. 알파는 각 그림자의 블렌드 강도로 취급된다 |
| 範囲 | 범위 | 그림자가 지는 범위 |
| ぼかし | 블러 | 0이면 애니메이션풍, 올리면 일러스트풍, 더 올리면 리얼풍. RGB가 그림자색 1·2·3에 대응 |
| ノーマルマップ強度 | 노멀 맵 강도 | 그림자에 노멀 맵을 적용하는 강도 |
| 影を受け取る | 그림자 받기 | 다른 오브젝트의 그림자를 받는다. **지붕이 있는 공간에서 위화감이 생겨 끄는 편이 나은 경우가 많다** |
| 境界の色 / 境界の幅 | 경계의 색 / 폭 | 그림자 경계에 색을 얹는다. 서브서피스 스캐터링 같은 효과에 쓸 수 있다 |
| コントラスト | 콘트라스트 | 메인 컬러를 한 번 더 곱해 그림자 색을 선명하게 한다 |
| 影色への環境光影響度 | 그림자색에 대한 환경광 영향도 | 그림자색을 검게 두고 이 값을 1로 하면 Standard Shader에 가까운 그림자색이 된다 |
| AO Map | AO Map | 어두운 부분일수록 그림자가 잘 나온다. RGB가 그림자색 1·2·3에 대응 |
| Min・Max | Min·Max | AO Map을 이 범위로 리매핑한다 |

문서는 그림자색이 어떻게 계산되는지도 식으로 밝혀두고 있다. 파라미터가 서로
어떻게 얽히는지 알 수 있어서, 값만 만지는 것보다 이해가 빠르다.

```text
影色 = (影色テクスチャがあれば影色テクスチャ、なければメインカラー)
       * カラーピッカーの影色
       * lerp(1.0, メインカラー, コントラスト);

最終的な影色 = lerp(影色, メインカラー, 環境光 * 影色への環境光影響度);
```

그림자색은 **(그림자색 텍스처가 있으면 그것, 없으면 메인 컬러) × 컬러 피커의
그림자색 × `lerp(1.0, 메인 컬러, 콘트라스트)`** 이고, 최종 그림자색은 거기에
환경광 영향도만큼 메인 컬러 쪽으로 `lerp`한 값이다.

3단계 그림자가 합쳐지는 순서는 이렇다.

```text
影色2・3の合成結果 = lerp(影色3, 影色2, 3影のライティング);
全影の合成結果     = lerp(影色2・3の合成結果, 影色1, 2影のライティング);
最終結果           = lerp(全影の合成結果, メインカラー, 1影のライティング);
```

안쪽(3)에서 바깥쪽(1)으로 차례로 섞고, 마지막에 메인 컬러와 섞는다.

### RimShade

**모델 윤곽에 그림자를 넣어** 입체감을 낸다. 문서 표현대로 림 라이트가 그대로
그림자로 동작하는 것이고, 일러스트풍보다는 3DCG적인 효과가 난다.

| 일본어 | 한국어 | 설명 |
|---|---|---|
| 色 / マスク | 색 / 마스크 | RimShade의 색과 마스크. R 채널 사용 |
| ノーマルマップ強度 | 노멀 맵 강도 | 노멀 맵 적용 강도 |
| 範囲 | 범위 | 그림자가 지는 범위 |
| ぼかし | 블러 | 0이면 애니메이션풍, 올리면 리얼풍 |
| リムライトの細さ | **림 라이트의 가늘기** | 이른바 **프레넬** 파라미터. 콘트라스트를 강하게 해서 림을 가늘게 만든다 |

마지막 항목이 서두에 말한 그 항목이다. **「벌금」이 아니라 「가늘기」**이고,
프레넬 콘트라스트를 조절한다.

### 발광 설정 (発光設定)

LED나 조명처럼 **스스로 빛을 내는 것**에 쓴다. 라이트 강도와 무관하게 지정한
색이 가산되기 때문에 어두운 공간에서 특히 잘 드러난다.

| 일본어 | 한국어 | 설명 |
|---|---|---|
| 色 | 색 | 발광 색. 옆 삼각형에서 UV 설정 |
| マスク | 마스크 | 발광 위치와 강도. RGBA 채널 사용 |
| 点滅の強さ / タイプ / 速度 / ズレ | 점멸의 강도 / 타입 / 속도 / 어긋남 | 타입을 끄면 부드럽게, 켜면 뚜렷하게 점멸한다 |
| グラデーション | 그라데이션 | 색을 시간에 따라 변화시킨다 |
| 視差の強さ | 시차의 강도 | 보는 각도에 따라 UV를 어긋나게 한다 |
| 蛍光 | 형광 | 어두울 때만 빛난다. 다만 빛이 완전히 없는 공간에서는 빛나지 않는다 |

## 노멀 맵·광택 설정 (ノーマルマップ・光沢設定)

### 노멀 맵 (ノーマルマップ設定)

노멀 맵은 **단독으로는 아무것도 바꾸지 않는다.** 그림자·림 라이트 등이 적용되는
방식에 영향을 줄 뿐이다. 2장까지 쓸 수 있어서, 1장째로 큰 음영을 잡고 2장째로
디테일을 더하는 식으로 나눠 쓴다. **마스크는 2장째만 지원한다.**

노멀 맵이 영향을 주는 항목은 문서에 이렇게 나열되어 있다 — 그림자, 역광 라이트,
광택, 매트캡, 림 라이트, 라메, AudioLink, 굴절, 보석.

### 역광 라이트 (逆光ライト)

일러스트에서 자주 쓰는 **뒤에서 빛이 비쳐 드는** 표현이다. 그림자를 받고 라이트를
추종할 수 있어서 림 라이트와는 빛이 들어오는 방식이 조금 다르다.

| 일본어 | 한국어 | 설명 |
|---|---|---|
| 色 | 색 | 역광 라이트의 색 |
| 範囲 / ぼかし | 범위 / 블러 | 빛나는 범위와 흐림 정도 |
| 指向性 | 지향성 | 라이트 방향에 따라 밝기를 바꾸는 정도 |
| 視線方向の影響度 | 시선 방향의 영향도 | 시선 방향에 따라 빛의 범위를 바꾼다 |
| 影を受け取る | 그림자 받기 | 다른 오브젝트의 그림자를 받는다 |
| 裏面で無効化 | 뒷면에서 무효화 | 뒷면에서 끈다 |

### 광택 (光沢設定)

일러스트의 하이라이트부터 환경광을 반사하는 사실적 표현까지 담당한다. 큐브맵을
지정해 반사광을 커스터마이즈할 수 있다.

| 일본어 | 한국어 | 설명 |
|---|---|---|
| 滑らかさ | 스무스니스 | 표면의 매끄러움. 낮출수록 반사가 부드러워진다. R 채널 사용 |
| 金属度 | 메탈릭 | 금속스러움. R 채널 사용 |
| 反射率 | 반사율 | 환경광의 반사율 |
| 色 | 색 | 반사의 색 |
| 光沢のタイプ | 광택 타입 | 라이트를 반사시키는 형태 |
| 複数ライトから光沢を生成 | 여러 라이트에서 광택 생성 | 포인트·스포트 라이트에서도 광택을 만든다 |
| 環境光の反射 | 환경광 반사 | 주변 색을 반사시킨다 |
| 合成モード | 합성 모드 | 통상 / 가산 / 스크린 / 곱하기 |

### 매트캡 (マットキャップ設定)

매트캡은 **카메라 방향에 맞춰 움직인다.** 구체에 하이라이트를 칠하는 형태로
텍스처를 그리면 되고 라이팅 환경에 따라 변하지 않아서 다루기 쉽다.

| 일본어 | 한국어 | 설명 |
|---|---|---|
| マットキャップ | 매트캡 | 매트캡 텍스처 |
| UV1を合成 | UV1 합성 | UV1을 매트캡 UV로 블렌드한다. 머리카락에 정면에서 UV1을 투영하고 y축을 합성하면 상하 방향 움직임을 제한할 수 있어 **머리카락 하이라이트 재현에 적합**하다 |
| Z軸回転キャンセル | Z축 회전 취소 | VR에서 목이나 카메라를 기울였을 때의 회전을 억제한다 |
| パース補正 | 원근 보정 | 화면 가장자리에서도 어긋남 없이 투영되게 한다 |
| VR時の視差の強さ | VR 시 시차의 강도 | VR에서 「번쩍이는 느낌」을 조정한다 |
| マスク | 마스크 | 적용할 부분. RGB 채널 사용 |
| ライティングを適用 | 라이팅 적용 | 어두운 라이팅에서 색이 뜨는 것을 억제한다 |
| 影部分で無効化 / 裏面で無効化 | 그림자 부분 / 뒷면에서 무효화 | 해당 부분에서 매트캡을 끈다 |
| 合成モード | 합성 모드 | 통상 / 가산 / 스크린 / 곱하기 |
| カスタムノーマルマップ | 커스텀 노멀 맵 | 매트캡 전용 노멀 맵 |

### 림 라이트 (リムライト設定)

**빛이 돌아 들어오는** 표현이다. 윤곽에 하이라이트가 들어가 캐릭터를 배경에서
떠오르게 한다.

| 일본어 | 한국어 | 설명 |
|---|---|---|
| 色 / マスク | 색 / 마스크 | 부분적으로 색을 바꾸거나 무효화할 수 있다 |
| 範囲 / ぼかし | 범위 / 블러 | 0이면 애니메이션풍, 올리면 부드러운 인상 |
| リムライトの細さ | **림 라이트의 가늘기** | 프레넬 파라미터. 콘트라스트를 강하게 해 림을 가늘게 한다 |
| ライティングを適用 | 라이팅 적용 | 어두운 라이팅에서 색이 뜨는 것을 억제한다 |
| 影部分で無効化 | 그림자 부분에서 무효화 | 그림자 부분에서 끈다 |
| 裏面で無効化 | 뒷면에서 무효화 | **옷 안쪽이 부자연스럽게 빛날 때** 쓴다 |
| ライト方向の影響度 | 라이트 방향의 영향도 | 직접광 부분과 간접광 부분에 개별로 블러·범위·색을 줄 수 있다 |
| 直接光の幅 / 間接光の幅 | 직접광의 폭 / 간접광의 폭 | 각각의 범위 |
| ノーマルマップ強度 | 노멀 맵 강도 | 노멀 맵 적용 강도 |
| VR時の視差の強さ | VR 시 시차의 강도 | VR에서의 시차 |

### 라메 / 글리터 (ラメ設定)

반짝이는 질감을 만든다.

## 확장 설정 — 아웃라인 (輪郭線設定)

선화에 해당하는 기능이다. 텍스처로 두께를 조절할 수 있어 입·빼기 표현이나
부분 마스크가 되고, 텍스처에서 색을 가져오면 색 트레스도 된다.

문서가 짚는 부분이 하나 있다. 얼굴 셰이딩을 위해 노멀을 조정한 모델이나 하드
엣지 모델은 **원래 윤곽선이 매끄럽게 안 나오는데**, lilToon은 **정점 컬러에
노멀 정보를 기록**해서 매끄럽게 그린다.

| 일본어 | 한국어 | 설명 |
|---|---|---|
| テクスチャ | 텍스처 | 오른쪽 컬러 피커로 색을 정할 수도 있다 |
| 色相 / 彩度 / 明度 / ガンマ | 색상 / 채도 / 명도 / 감마 | 색조 보정 |
| 焼き込み | 베이크 | 보정한 텍스처를 내보낸다 |
| ハイライト | 하이라이트 | 「메인 컬러에서 색 가져오기」를 켜면 텍스처 색이 곱해진다. Min·Max로 범위를 정한다 |
| ライティングを適用 | 라이팅 적용 | 라이팅에 의한 밝기 변화를 적용한다 |
| マスクと太さ | 마스크와 두께 | 검게 칠한 부분에는 윤곽선이 나오지 않는다. R 채널 사용 |
| 太さを補正 | 두께 보정 | 거리에 의한 두께 변화를 보정한다 |
| 頂点カラー | 정점 컬러 | None / R→Width / RGBA→Normal & Width |
| 太さ0の頂点を削除 | 두께 0인 정점 삭제 | 두께가 0인 부분의 정점을 삭제해 렌더링에서 뺀다 |
| Z Bias | Z Bias | 윤곽선을 앞뒤로 이동시킨다 |
| ノーマルマップ | 노멀 맵 | 윤곽선을 **밀어내는 방향**을 조정한다 |

마지막 항목의 「밀어낸다(押し出す)」와 정점 노멀을 두께에 쓰는 설계를 보면
노멀 방향으로 확장하는 방식으로 보이지만, **문서가 렌더링 방식을 명시하지는
않는다.** 확실한 건 위 두 문장까지다.

## 문서를 볼 때 걸리는 것들

대조하면서 발견한, 원문 자체의 문제들이다. 확인 시점은 2026-08-26이고 각
항목의 위치를 링크로 달아뒀다.

### `Min・Max` — 항목명과 설명이 어긋난다

[影設定](https://lilxyzw.github.io/lilToon/ja_JP/color/shadow.html) 페이지의 `パラメーター` 절

> AO Mapを **Mix** ～Maxの範囲で再マッピングします。

항목명은 `Min・Max`인데 설명은 `Mix～Max`다. 값의 의미상 `Min`이 맞으므로
설명 쪽 오타로 보인다.

### `Atras` — 한 문장 안에서 표기가 갈린다

[ラメ設定](https://lilxyzw.github.io/lilToon/ja_JP/reflections/glitter.html) 페이지의 `パラメーター` 절

> 形状のマスクテクスチャが **Atras** 化されている場合の縦横の **アトラス** 数の設定です。

같은 문장에서 앞은 로마자 `Atras`, 뒤는 가타카나 `アトラス`다. 텍스처
아틀라스(atlas)를 가리키는 것이 분명하므로 `Atras` 쪽이 오타다. 항목명 자체가
`Atras`라 인스펙터에서도 그렇게 보인다.

### `コントラスト（後処理）` — 없는 항목을 참조한다

[ラメ設定](https://lilxyzw.github.io/lilToon/ja_JP/reflections/glitter.html) 페이지의 `パラメーター` 절

> 後処理で適用されるコントラストです。 **前述のコントラスト** は一定以下の明るさをカットするのに対し、こちらはガンマ値を調整することで密度を制御します。

「앞서 언급한 콘트라스트」를 참조하는데, 이 페이지의 파라미터 목록에 단독
`コントラスト` 항목이 없다. 목록은 `UV Mode`부터 `コントラスト（後処理）`까지
21개이고 그 안에 없다.

### 광택 설정의 Cubemap — 개요에만 있고 항목이 없다

[光沢設定](https://lilxyzw.github.io/lilToon/ja_JP/reflections/reflection.html) 페이지의 `概要` 절

> **Cubemapを指定することで** 反射光をカスタマイズできるため様々な使い方ができます。

개요는 이렇게 안내하는데, 같은 페이지의 `パラメーター`
목록은 `滑らかさ` `金属度` `反射率` `色` `光沢のタイプ`
`複数ライトから光沢を生成` `環境光の反射` `合成モード` 8개뿐이고, Cubemap을
지정하는 항목의 설명이 없다.

정상이니, 그때는 값을 직접 움직여 보는 편이 빠르다.

---

## 정리

- lilToon 인스펙터는 한국어를 지원하지만 **공식 문서는 일본어뿐**이다. 한국어
  2차 자료의 오역은 여기서 나온다.
- 그중 하나가 **「림 라이트의 벌금」**이다. 원문은 「リムライトの細さ」,
  **프레넬 콘트라스트를 조절하는 「가늘기」**다.
- 항목명이 헷갈릴 때는 **일본어 항목명으로 공식 문서를 찾는 게 가장 빠르다.**
  그래서 이 글에 일본어 항목명을 같이 실었다.
- 파라미터를 외우는 것보다, **그림자 계산식**처럼 문서가 밝혀둔 구조를 한 번
  읽어두는 편이 값을 만질 때 도움이 된다.
